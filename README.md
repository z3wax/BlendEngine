## Overview

**BlendEngine** is a custom 3D engine project built on top of the Blender source code.  
Its goal is to reshape Blender’s strong 3D creation foundation into a more focused environment for **real-time game development**, **interactive 3D production**, and **engine-level experimentation**.

Rather than functioning only as a content creation suite, BlendEngine is intended to evolve toward a more practical workflow for:

- real-time scene building,
- game-oriented editor tools,
- runtime-focused project structure,
- asset-driven pipelines,
- and interactive 3D development.

## Project Structure

<p align="center">
  <img src="docs/assets/diagrams/project-structure.png" alt="Project Structure Diagram" width="100%" />
</p>

BlendEngine development is expected to revolve around the following areas:

- **Engine Identity** — branding, naming, startup experience, and custom project structure.
- **Editor Layer** — UI changes, workflow changes, and tool organization.
- **Scene Workflow** — objects, hierarchy, asset handling, and interactive editing.
- **Runtime Direction** — future game-preview and build-oriented systems.
- **Tooling Extension** — scripting, templates, plugins, and engine-side utilities.

---

## Development Vision

BlendEngine is being developed with the following long-term direction:

### 1. Simpler Game Workflow
A more direct user experience for people who want to build playable projects, not only create 3D assets.

### 2. Cleaner Editor Experience
A structured and understandable interface for scene creation, asset control, and project organization.

### 3. Better Runtime Orientation
A workflow that increasingly supports game logic, runtime testing, export readiness, and iteration speed.

### 4. Creator and Developer Balance
An environment where artists, technical users, and indie developers can work inside a more unified production space.

### 5. Open Source Continuity
A project direction that respects and builds upon the open-source foundation provided by Blender.

At this stage, the repository primarily represents:

## Technology Foundation

BlendEngine is based on the **Blender** source foundation.

That foundation provides a strong technical base for:

- 3D creation,
- animation systems,
- rendering workflows,
- simulation tools,
- scripting interfaces,
- and extensible tool development.

BlendEngine builds on this base with the intention of moving toward a more focused **game-engine-style workflow**.
