# BlendEngine

**BlendEngine** is a custom 3D game engine project built on top of the Blender source code.

The project aims to transform Blender’s powerful 3D creation foundation into a more game-development-focused engine, with a cleaner workflow, dedicated runtime features, and tools designed for building interactive 3D experiences.

> BlendEngine is currently in active development.

---

## Overview

BlendEngine is designed for creating real-time 3D games, simulations, interactive worlds, cinematic scenes, and experimental engine-level tools.

The main focus of the project is to combine Blender’s mature 3D ecosystem with a more direct and practical game engine workflow.

BlendEngine focuses on:

- Real-time 3D scene creation
- Game-oriented editor tools
- Interactive object workflows
- Runtime-ready project structure
- Custom engine UI improvements
- Asset management for game projects
- Better workflow for developers and creators

---

## Vision

The goal of BlendEngine is to create a modern 3D engine that is powerful, flexible, and easier to use for game development.

Instead of being only a 3D content creation suite, BlendEngine aims to provide a more complete environment for building playable 3D projects.

The long-term vision includes:

- A clean and focused game development interface
- Faster scene editing and project iteration
- Built-in game templates
- Better runtime preview tools
- Simplified asset and scene management
- Game-ready export workflows
- A developer-friendly engine structure

---

## Core Features

Planned and experimental features include:

---

## Project Goals

BlendEngine is built with the following goals:

### Simplicity

The editor should feel clean, understandable, and practical.  
Complex engine workflows should be easier to access and manage.

### Game Development Focus

Tools should be designed around building playable projects, not only creating 3D assets.

### Performance Awareness

The engine should help developers understand heavy assets, scene complexity, rendering cost, and optimization problems.

### Creator-Friendly Workflow

Artists, developers, and indie creators should be able to work inside one environment without constantly switching between many tools.

### Open Source Foundation

BlendEngine is based on Blender’s open-source technology and follows the responsibilities that come with that foundation.
