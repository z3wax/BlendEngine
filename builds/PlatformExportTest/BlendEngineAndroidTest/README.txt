New BlendEngine Game

Run this package with:
  ./run_game.sh

Or open BlendEngineAndroidTest.blend in BlendEngine and press Run Game in the Play Mode page.

Controls:
  W/A/S/D move, Space jump, Shift sprint, F attack, R aim, E interact, Esc stop.

Optimization:
  This package includes editor_tools, multiplayer, runtime_optimization, and performance_budget data.
